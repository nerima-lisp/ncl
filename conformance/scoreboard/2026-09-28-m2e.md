## ansi-test

`doit.lsp` の load 中に `ncl: lowering error: Ir { detail: "AArch64 calls support at most four register arguments" }` で exit 1、stdout 0 bytes、stderr 121 bytes、選択項目数 0 で停止しました。停止箇所は `doit.lsp:6` の `(load "init.lisp")` 処理中と推定されますが、内部 form は stderr に出力されず特定不能です。`passed/failed/unexecuted` は算出不能です。elapsed は 0.13 s でした。

## 失敗原因分類

分類単位は個別ベンチ入口、cl-bench aggregate 入口、または ansi-test suite 入口の実行です。最初に出た stderr の非空行を優先しました。観測された異なる原因は2種類だけなので、上位10件に満たない行を追加していません。aggregate は個別65件とは別の追加診断です。

| rank | エラーの種類 | 最小の再現式（`ncl --eval` で実測） | 影響件数 | 該当しそうな crate または箇所 |
| ---: | --- | --- | ---: | --- |
| 1 | AArch64 の5引数以上呼び出し | `ncl --eval '(make-pathname :directory (quote (:relative :wild)) :name :wild :type "fasl")'` | 1（ansi-test suite） | `packages/compiler/front/src/lower/expr.rs:121-132`（verified: 5引数以上かつ keyword symbol を含む call の lowering） |
| 2 | `object error: TypeError` | `ncl --eval '(load "package.lisp")'` | 66（cl-bench 個別65 + aggregate 1） | `packages/lib/macros/src/packaging.rs:168-202`（推定: `DEFPACKAGE` の clause head/designator 処理） |

1位は ansi-test では `ncl --load doit.lsp < /dev/null` で観測し、上表の `--eval` は同じ lowering error を最小 form で再現したものです。2位の cl-bench は完走ベンチがなく、完走 elapsed はありません。個別入口の表示値を再集計した合計は 7.2767 s、elapsed 範囲は 0.0575--0.3590 s でした。

## 再現コマンド

release build:

~~~sh
<ncl-cargo-wrapper> build --release -p ncl
~~~

ansi-test:

~~~sh
cd <ansi-test-checkout>
../target/release/ncl --load doit.lsp < /dev/null
~~~

cl-bench aggregate:

~~~sh
cd <cl-bench-checkout>
../target/release/ncl --eval '(load "package.lisp")'
~~~

cl-bench individual entries use the same three loads followed by the selected `cl-bench:bench-run-1` call. The pinned source checkouts were acquired with `scripts/conformance_scoreboard.py`'s `checkout_source`; source hashes were verified. No implementation or script change was made.
